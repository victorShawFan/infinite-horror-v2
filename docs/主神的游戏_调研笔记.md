# Steam「主神的游戏」设计调研笔记
> 来源: https://store.steampowered.com/app/3565290/_/?l=schinese
> 开发商: ZodiacStudio | 发行日期: 2026-07-17 | 评价: 多半好评(86)

## 核心玩法
- **无限流Roguelike多世界冒险** — 穿梭九个风格迥异的世界
- **像素风格俯视角** — 2D俯视角动作探索
- **每世界独立规则** — 灵异、末世、丧尸、魔幻等不同主题
- **Roguelike重复可玩** — 每次世界顺序随机，支线/掉落变化

## 可借鉴的系统设计

### 1. 技能芯片系统（40+种）
- **热插拔** — 芯片可随时更换，改变技能形态
- 改变技能轨迹、攻击性质、弹道属性
- 深度构筑(Build)系统

### 2. 血统进化系统（68种）
- 不同血统搭配产生化学反应
- **纯血进化** — 全部同一血统触发最终进化
- **变异进化** — 混合血统触发意外变异
- 巨大的构筑自由度

### 3. 商店/商人系统
- 武器商人（刀剑、枪械、弓箭等丰富品类）
- 装备有详细属性面板(Attack Power, Attack Speed等)
- 金币系统购买

### 4. 主神空间（整备区）
- 世界之间的休息/准备区域
- 倒计时进入下一个世界
- 可购买/升级/调整Build

## 用户评价中提到的优缺点
### 优点
- 无限流题材吸引人
- 血统和芯片构筑有深度
- 跨世界串联剧情有创意

### 缺点（我们要避免）
- 平衡性问题（智力流太强）
- 存档系统曾经缺失
- 局外成长较少
- 流程重复感（5-6局后）
- 强化内容还不够多

## 对我们游戏的启发
1. **血统系统要有真实差异化** — 纯血/混血不同路线
2. **技能芯片要热插拔** — 可视化改变效果
3. **主神空间要有购物/强化的沉浸感** — 不只是简单菜单
4. **每层要有不同的视觉主题和规则** — 不能只换皮
5. **数值平衡** — 多种流派都要可行
6. **存档必须可靠** — 每层自动存档
