# 回合制重构实施计划

1. 为纯战斗引擎编写失败测试，覆盖速度序列、单体/群体目标、MP、防御和胜负。
2. 实现 `SkillCatalog` 与 `TurnBattleEngine`，使引擎测试通过。
3. 为主神空间技能学习编写失败测试，实现奖励点消费、前置条件和已学习校验。
4. 创建 `rebuild.html`、应用状态机和电影化 UI，不引用旧 `main.js`。
5. 接入首章角色、敌人、背景和三场战斗数据，形成奖励闭环。
6. 配置 Vite 多页面构建并执行引擎、构建、旧版回归测试。
7. 使用 Chrome 完成真实交互验收，修复 console、布局和流程问题。
8. 提交首章垂直切片；验证通过后再迁移探索和剩余章节。

## Review Focus

- 群体技能是否只命中存活合法目标；
- 防御是否在正确时点清除；
- 非法行动是否错误消耗 MP 或回合；
- 同速排序是否确定；
- 战斗结束后是否重复结算奖励。
