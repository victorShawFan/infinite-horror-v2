# 《无限恐怖》回合制重构设计

## 决策

采用“内容资产复用、核心架构重建”。旧版保留在 Git 历史中；新核心放入
`src/rebuild`，完成首章垂直切片并通过运行验收后再替换默认入口。

## 首阶段目标

交付一个独立可玩的首章战斗切片，证明以下主循环成立：

1. 主神空间查看并学习技能；
2. 进入生化危机战斗；
3. 每名我方角色按速度获得行动回合；
4. 玩家主动选择普通攻击、单体技能、群体技能、防御、道具或逃跑；
5. 单体技能必须选择目标，群体技能会命中全部合法目标；
6. 敌人显示下一步意图并按规则行动；
7. 战斗奖励回到主神空间，形成学习新技能的闭环。

## 保留内容

- `public/assets` 中可用的背景、角色与敌人 JPG；
- 12 章剧情、关卡、敌人、技能、血统、装备和主神空间数据；
- 纯数据工具、随机数、关系、日志与已有验证脚本；
- 旧版 Git 历史，作为迁移来源和回归依据。

## 新架构

### 纯逻辑层

- `TurnBattleEngine`：唯一战斗状态机，不依赖 DOM；
- `SkillCatalog`：统一描述目标类型、消耗、倍率、范围和状态；
- `SkillLearning`：主神空间技能学习、前置条件、奖励点消费；
- 所有计算返回结构化事件，UI 只负责演出。

### 表现层

- `RebuildApp` 管理 TITLE / HUB / BATTLE / REWARD 四个界面状态；
- 战斗使用全屏电影化舞台，背景图、人物卡、敌人卡和行动时间轴分层；
- 桌面优先，同时保证 900px 宽度仍可操作；
- 技能按钮明确标注“单体/群体/辅助”、MP、冷却和伤害预估。

### 数据流

`
存档档案 → 主神空间学习技能 → 生成战斗快照
→ TurnBattleEngine 处理行动 → 结构化事件驱动动画
→ 战斗奖励写回档案 → 返回主神空间
`

## 战斗规则

- 每轮按 SPD 从高到低排序；同速由稳定序号决定；
- 我方行动必须由玩家确认；敌方行动由意图 AI 自动执行；
- 普通攻击零消耗、单体；
- 单体技能只接受一个存活合法目标；
- 群体技能自动命中全部存活合法目标；
- 防御持续到该角色下一次行动前，受到伤害降低 50%；
- MP 不足、目标非法、技能冷却时拒绝行动且不消耗回合；
- 全体敌人死亡为胜利，全体我方死亡为失败。

## 验证门槛

- 纯引擎自动测试覆盖目标校验、单体、群体、MP、防御、速度顺序、胜负；
- Vite 构建包含 `rebuild.html`；
- Chrome 实机无 console error，能完成“学习技能→群攻战斗→胜利→领奖”；
- 首屏、主神空间和战斗画面各保留一张运行截图用于视觉复核。
