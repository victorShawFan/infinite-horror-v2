# 《无限恐怖：中洲轮回》

> 基于 zhttty 同名小说改编的2D俯视角 Roguelike 魔塔式RPG

## 🎮 快速开始

```bash
npm install
npm run dev -- --port 3001
# 浏览器打开 http://localhost:3001
```

## 📖 游戏简介

玩家扮演郑吒，被神秘的「主神」投入经典恐怖电影世界中进行生存试炼。第一章进入《生化危机》世界，在蜂巢实验室中与丧尸、爬行者和暴君战斗，同时经历队友的生离死别和自身力量的觉醒。

## ⌨️ 操作说明

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动 |
| 空格 / Enter | 对话 / 确认 / 查看邻近敌人战力 |
| G | 基因锁开关（激活后攻防大幅提升） |
| I | 状态 / 装备面板 |
| H | 帮助面板 |
| L | 战斗日志 |
| M | 全地图视图 |
| ESC | 关闭面板 / 跳过过场动画 |

## 🗺️ 第一章：名为生化（6层）

1. **列车醒来** — 教学层，认识队友，了解规则
2. **蜂巢入口** — 护送层，遭遇更强的感染者
3. **红后机房** — 解谜层，操作终端恢复电力
4. **激光通道** — 危险层，穿越激光陷阱
5. **丧尸与爬行者** — 剧情高潮，牟钢牺牲，基因锁觉醒
6. **六小时回归** — Boss战，击败暴君T-002，章节结算

## ⚔️ 核心系统

### 魔塔式战斗
- 走入敌人自动触发回合制对撞战斗
- 悬停鼠标或按空格预判能否胜利
- 合理收集属性晶石是通关关键

### 血统系统
- **血族** — ATK+15%，击败敌人吸血
- **古武** — ATK+20%，近战加成
- **武修** — DEF+20%，反伤效果
- **道法** — 开启法力值，法术伤害

### 基因锁
- 特定剧情触发觉醒
- 按G激活：ATK+20%×阶数，DEF+15%×阶数
- 关键Boss战前的必备强化

### 技能芯片
- 最多装备4个芯片
- 改变攻击属性（火/冰/暴击/生命/速度）

### 主神空间
- 章节结算后进入
- 消耗奖励点强化属性、购买血统、装备芯片

## 🎨 技术架构

- **渲染**: Canvas 2D + 程序化精灵
- **构建**: Vite + ES Modules
- **音效**: Web Audio API 程序化生成
- **存档**: localStorage 自动保存
- **资产**: 23张AI生成美术资产
