# 无限恐怖：中洲轮回

> 2D 俯视角 Roguelike 地牢探索 + 魔塔式数值战斗 + 叙事选择

## 🎮 游戏简介

基于小说《无限恐怖》的世界观，你将扮演**郑吒**，在"主神"的安排下穿越恐怖片世界。

游戏核心不是射击，而是**策略性的数值管理**与**剧情选择**：

- 🗺️ **地牢探索**：走格子探索危险区域，收集道具和钥匙
- ⚔️ **魔塔式战斗**：碰到敌人自动战斗，结果由数值决定——碰之前先想清楚能不能打赢
- 🧬 **基因锁系统**：4阶解锁，战斗中按G激活获得属性加成
- 🩸 **血统构筑**：血族/古武/武修/道法四大流派
- 💎 **技能芯片**：5种芯片热插拔，最多装4个
- 📖 **叙事选择**：每个房间都可能有剧情事件，选择影响结果
- 🏛️ **主神空间**：通关后用奖励点购买强化、血统、装备

## 📋 第一章 · 名为生化

6个地牢层，对应原著第一关（生化危机一）：

1. **列车醒来** — 教学层，认识队友，学习战斗规则
2. **蜂巢入口** — 调查遗体、收集钥匙、遇到更强敌人
3. **红后机房** — 三终端解谜（照明→门控→主电源），触发伏兵
4. **激光通道** — 躲避激光（踩上扣15%HP），对抗变异猎犬
5. **爬行者** — 牟钢固定阵亡剧情 → 基因锁一阶觉醒
6. **六小时回归** — 补给三选一 → 最终Boss暴君T-002 → 结算

通关后进入**主神空间**进行十日整备。

- **渲染**: Canvas 2D + 程序化像素纹理
- **音效**: Web Audio API 程序化合成

## 📐 数值系统

### 战斗公式
```
玩家伤害 = max(1, 玩家ATK - 敌人DEF)
敌人伤害 = max(1, 敌人ATK - 玩家DEF)
击杀回合 = ceil(敌人HP / 玩家伤害)
总受伤 = 敌人伤害 × (击杀回合 - 1)  // 玩家先手
```

### 基因锁加成
```
ATK加成 = ATK × 20% × 阶数
DEF加成 = DEF × 15% × 阶数
```

### 血统加成
| 血统 | 效果 |
|------|------|
| 血族 | ATK +15% |
| 古武 | ATK +20% |
| 武修 | DEF +20% |
| 道法 | 开启法力值 |
